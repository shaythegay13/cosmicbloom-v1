## 🆘 Need Help?

**If Unity won't install:**
- Make sure you have 10GB free space
- Run Unity Hub as Administrator
- Check your internet connection

**If project won't create:**
- Choose a different location
- Make sure folder name has no spaces
- Try closing and reopening Unity Hub

**If character won't move:**
- Make sure script is attached to Player
- Check Console window for errors (Window → General → Console)
- Press Play button to test
