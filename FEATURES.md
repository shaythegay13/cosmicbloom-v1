# Farm & Give - Features & Roadmap

## ✅ Implemented Features

### Core Game Mechanics
- **5 Unique Characters** - Each with special farming bonuses
  - Sunny (☀️) - Crops grow 10% faster
  - Luna (🌙) - Night crops yield double
  - Terra (🌍) - Soil quality bonus 15%
  - River (💧) - Water efficiency 20%
  - Sage (🧙) - Experience gain 25%

- **Farming System**
  - Till soil to prepare for planting
  - Plant seeds (carrots, tomatoes, wheat, corn)
  - Water crops to help them grow
  - Harvest fully grown crops for coins
  - Crops grow in real-time with multiple stages

- **World Exploration**
  - 30x30 tile procedurally generated farm
  - Grass, trees, rocks, and fences
  - Smooth camera following player
  - Collision detection

- **Player Progression**
  - Level system with experience points
  - Coin economy for purchases
  - Inventory management
  - Auto-save every 30 seconds

### Backend Features
- **User Authentication**
  - Secure registration and login
  - JWT token-based authentication
  - Password hashing with bcrypt

- **Game State Persistence**
  - Save/load game progress
  - Farm state preservation
  - Inventory tracking
  - Character selection saved

- **Charity System**
  - 10% of purchases go to selected charity
  - Database of 10+ real community gardens
  - Search by city/state
  - Track total donations and impact
  - User contribution tracking

- **Payment Integration**
  - Stripe payment processing ready
  - Transaction history
  - Automatic charity allocation
  - Secure payment handling

### UI/UX Features
- **Responsive Design** - Works on desktop and mobile
- **Modal System** - Shop, charity, and menu modals
- **HUD Display** - Level, coins, and stats
- **Tool Selection** - Easy-to-use toolbar
- **Character Selection Screen** - Beautiful character cards
- **Auth System** - Clean login/register interface
